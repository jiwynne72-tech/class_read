# Time to Read - Classic & Easy Literature

A web-based reading comprehension application designed to make literature accessible to readers of all levels. The app features dual reading modes—**The Classics** and **Easy Reading**—complete with text summaries, audio playback, interactive quizzes, vocabulary highlights, and discussion prompts.

---

## 🚀 Features

* **Dual Reading Modes:**
  * **📚 Classic Literature:** Excerpts from famous classic works (e.g., *Pride and Prejudice*, *Moby-Dick*, *The Great Gatsby*).
  * **⭐ Easy Reader:** Simplified passages suitable for beginner readers or English language learners.
* **Randomized Selection:** Passages are shuffled dynamically upon initialization and user request.
* **Interactive Comprehension Quizzes:** True/False questions with instant feedback.
* **Accessibility & Audio:** Integrated Text-to-Speech (TTS) using the Web Speech API.
* **Educational Tools:** 
  * "Summarize" toggle for quick comprehension.
  * Key vocabulary tags with definitions.
  * Thought-provoking discussion prompts for classroom or individual use.
* **Single-File Architecture:** Pure HTML, CSS, and Vanilla JavaScript—no extra dependencies or build tools required.

## 🛠️ Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Apple Safari, or Microsoft Edge).

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/time-to-read.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd time-to-read
   ```
3. **Open the application:**
   Simply double-click `index.html` or open it with your preferred browser.
